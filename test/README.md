# 測試

不需要連 Supabase，也不需要開瀏覽器；用 jsdom 把頁面實際跑起來，抓執行期錯誤與計算錯誤。

## 執行方式

先安裝一次 jsdom（只需一次）：

```bash
npm install
```

再執行三支測試：

```bash
npm test
```

## 三支測試各自負責什麼

| 檔案 | 檢查內容 |
|---|---|
| `logic.test.js` | 直接從 `teacher.html` 取出計算函式，驗證「只計實到課次」的金額邏輯，以及本地日期／月份不會因時區偏移 |
| `pages.test.js` | 三個頁面在 jsdom 載入後不可有任何 runtime error；並確認關鍵元素存在 |
| `interact.test.js` | 模擬點擊：切換九個分頁、開課次編輯器、確認財務金額與出席狀態一致 |

## 為什麼要有這些測試

這個專案沒有建置流程、所有邏輯都寫在 HTML 內嵌的 script 裡，改動很容易在沒察覺的情況下弄壞其他地方。
這些測試可以在推上 Vercel 之前先攔下明顯的錯誤。
