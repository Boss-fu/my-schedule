# 我的班表

個人補教班表小工具 — 用電腦或手機瀏覽器打開 `index.html` 即可使用。

## 功能
- 暑假 / 秋季兩張班表一鍵切換
- 週檢視 / 單日檢視（手機自動用單日）
- 每個時段用下拉選單排課，可排多堂、可標「休」
- 顏色分類：茲茲教務 / 輔導課 / 諾貝爾輔導 / 家教 / 休假
- 「管理」面板：新增・改名・刪除課程、改類別顏色、編輯備註
- 匯出 / 匯入 JSON 備份、列印或存 PDF
- 資料存在瀏覽器本機（localStorage），修改自動保存

## 備份與同步
在一台裝置按「匯出備份」下載 `.json`，到另一台裝置「匯入備份」即可同步。
